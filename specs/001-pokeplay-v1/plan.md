# Implementation Plan

## Build
- Use the Sites/Vinext starter in this repo.
- Replace the starter skeleton with a custom multi-page site.
- Keep the UI low-maintenance by using the logo, brand colors, and CSS product cards instead of screenshots.
- Add route metadata, Open Graph metadata, FAQ schema, and OnlineStore schema.

## Content
- Lead with live Pokemon card auctions and Whatnot following.
- Support the future store without publishing empty product categories as standalone pages.
- Use flexible stream language because the schedule changes.
- Use "Utah-based, shipping nationwide" as a trust signal, not a local-only SEO strategy.

## Validation
- Production build must pass.
- Rendered HTML test should verify the starter preview is gone and PokePlay content is present.
- Primary links should point to the Whatnot profile.
